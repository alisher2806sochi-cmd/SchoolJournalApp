# Приложение для школьного журнала

Как запустить проект:
1. **На странице репозитория GitHub** нажмите зелёную кнопку `Code`.
2. В выпадающем меню выберите `Open with Visual Studio`.
3. Если появится диалоговое окно — укажите пустую папку на компьютере.
4. Нажмите Клонировать (Clone).
5. Visual Studio автоматически:
   - Скачает проект
   - Откроет решение
   - Восстановит зависимости
6. Нажмите F5, чтобы запустить приложение.
